## Commands available now

```sh
pnpm install --frozen-lockfile
pnpm verify:setup
pnpm --filter @tenday/convex exec tsc --noEmit --project src/tsconfig.json
pnpm --filter @tenday/convex exec convex dev --once --typecheck enable
pnpm dev:backend
```

The last command is a long-running development process; the `--once` form is a bounded deployment/typecheck check. Do not publish a production deployment just to verify setup.

Production environment variables must be configured separately if production is later requested.
